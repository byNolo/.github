# byNolo

**Independent software development. Based in Ontario, Canada.**

byNolo is a small software business focused on building practical, thoughtfully designed products. We work across web applications, mobile experiences, and the systems behind them.

The projects here are at different stages of development, from experiments to products in active testing.

### What we're building

**[Nookfield](https://github.com/byNolo/Nookfield)**  
Real-time coordination for groups moving through the real world. Event planning, live maps, routes, and location sharing with clear privacy controls. Currently in private testing.

**[Draftory](https://github.com/byNolo/Draftory)**  
A sports drafting and simulation platform. Build a roster, simulate a season, and see how it performs. Starting with baseball, powered by a Rust simulation engine running in the browser.

### **Other projects**

[**Vinyl Vote**](https://github.com/SamN20/Vinyl-Vote?utm_source=chatgpt.com)\
A community-driven album voting platform.

[**Reel Review**](https://github.com/SamN20/Reel-Review?utm_source=chatgpt.com)\
A weekly movie rating and discussion platform.


### How we build

We favour straightforward interfaces, maintainable code, and infrastructure that fits the project rather than the other way around. Our work spans React, TypeScript, Flutter, Python, Rust, and cloud and self-hosted systems.
